========================================================================
🚀 HƯỚNG DẪN MÃ NGUỒN LOCKET GOLD SPACE (FULL BACKUP)
========================================================================

1. CẤU TRÚC THƯ MỤC:
   - src/                : Toàn bộ mã nguồn Vue 3, TypeScript, CSS, Components & Composables.
   - public/             : Tài nguyên tĩnh (ảnh, icon SVG, ảnh chụp hướng dẫn 8 bước).
     └── app-config.json : File cấu hình link tải DNS iOS & APK Android (Sửa link ở đây không cần build lại code).
   - dist/               : Bản build hoàn chỉnh (HTML, CSS, JS minified) - có thể upload thẳng lên Hosting/Vercel/Netlify để chạy luôn không cần cài Node.js.
   - index.html          : File HTML gốc của dự án.
   - package.json        : Danh sách thư viện và scripts (Vue, Vite, FontAwesome,...).
   - vite.config.js      : File cấu hình Vite.
   - tailwind.config.js  : Cấu hình Tailwind CSS.

========================================================================
2. CÁCH ĐỔI LINK TẢI DNS & APK (KHÔNG CẦN BUILD LẠI):
========================================================================
Mở file `public/app-config.json` (hoặc file `app-config.json` ở thư mục gốc web sau khi deploy):
{
  "dns": {
    "profileUrl": "Link_file_mobileconfig_cua_ban",
    "backupUrl": "Link_du_phong_dns",
    "fileName": "Locket_Gold_DNS.mobileconfig"
  },
  "android": {
    "apkUrl": "Link_tai_file_apk_cua_ban",
    "backupApkUrl": "Link_du_phong_apk",
    "fileName": "Locket_Gold_v2.6.0.apk",
    "versionName": "v2.6.0 Premium Unlocked",
    "fileSize": "48.5 MB"
  }
}
Chỉ cần sửa link trong file này và lưu lại, website sẽ tự động cập nhật ngay lập tức.

========================================================================
3. CÁCH CHẠY DỰ ÁN DÀNH CHO LẬP TRÌNH VIÊN (DEVELOPMENT):
========================================================================
Yêu cầu: Máy tính đã cài đặt Node.js (phiên bản 18+).

Bước 1: Mở Terminal / PowerShell tại thư mục này.
Bước 2: Chạy lệnh cài đặt thư viện:
   npm install

Bước 3: Khởi động máy chủ chạy thử (Dev Server):
   npm run dev

Bước 4: Mở trình duyệt vào địa chỉ:
   http://localhost:5173/

Bước 5: Khi muốn đóng gói sản phẩm để xuất bản (Build Production):
   npm run build
   -> Kết quả sẽ nằm trong thư mục `dist/`.

========================================================================
4. CÁCH DEPLOY LÊN HOSTING / SERVER:
========================================================================
- Cách 1 (Nhanh nhất): Upload toàn bộ các file bên trong thư mục `dist/` lên bất kỳ hosting tĩnh nào:
  + Vercel (kéo thả thư mục dist vào)
  + Netlify (kéo thả thư mục dist vào mục Deploy)
  + VPS / cPanel / DirectAdmin (upload vào public_html)
  + Cloudflare Pages

- Cách 2: Kết nối kho Git (GitHub / GitLab) với Vercel / Netlify:
  + Build Command: npm run build
  + Output Directory: dist
